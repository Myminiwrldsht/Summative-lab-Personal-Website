# Personal Portfolio Website

A personal portfolio site as a Junior Developer, showcasing background and projects.

## Sections

- **Header:** Name, title, and a link to my GitHub profile.
- **About:** A short bio covering my background, interests, and current focus areas.
- **Projects:** A responsive grid of project cards, each with an image, description, and a link to the live site or repo.

## Projects Featured

- **To-do App** — a task manager built to practice DOM manipulation and local storage.
- **Akan Name Generator** — calculates the day of the week a user was born and assigns them an Akan name.
- **Couture Link** — a Pinterest-inspired app connecting users with tailors for custom clothing.
- **JavaScript Calculator** — a calculator with arithmetic functions and history tracking.

## Built With

- HTML5
- CSS3 (Grid layout, media queries, hover transitions)

## Features

- Responsive 2-column project grid that collapses to 1 column on smaller screens (320px–768px).
- Hover effects on project cards (lift + shadow) and links (color change + underline).
- Equal-height project cards regardless of description length.
